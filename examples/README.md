# Synthetic input examples

These files contain fictional project records only.

- [sample_knowledge.jsonl](sample_knowledge.jsonl) illustrates a small dataset for testing ingestion, duplicate detection, retrieval and decision recency.
- The examples are **not** a Cognee API request schema and cannot be ingested without an adapter validated against a particular Cognee version.

Suggested retrieval questions:
- What storage option did DEMO-ATLAS select on January 5?
- What decision superseded it on January 7?
- Which records share the same source identifier?

Keep real exports, production indexes and actual audit logs outside the repository.
